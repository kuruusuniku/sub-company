# sub-company for Cowork — かんたんセットアップガイド

Claude デスクトップアプリ（Cowork）向けのガイドです。
ターミナルやプログラミングの知識は不要です。

---

## sub-company とは？

あなた専属の「子会社」をAIの中に作って、仕事を手伝ってもらうプラグインです。

秘書に話しかけるだけで、裏側の各部署が動いて仕事を進めてくれます。

```
あなた → 秘書に依頼 → 各部署が自動で動く → 結果が届く
```

---

## インストール方法

1. Claude デスクトップアプリを開く
2. 画面左下の **「カスタマイズ」** を開く
3. **「個人用プラグイン」** の **＋ボタン** をクリック
4. **「マーケットプレイスを追加」** を選択
5. `kuruusuniku/sub-company` と入力してインストール

---

## はじめかた（3ステップ）

### 1. 子会社を設立する

チャットに以下を入力してください：

```
/company setup cowork
```

秘書の名前とあなたの活動内容を聞かれるので、答えるだけでOKです。

### 2. 秘書に依頼する

```
/ask 来月のプロモーション案を考えて
```

日本語で自由に話しかけてください。秘書が内容を判断して、適切な部署に仕事を振ります。

### 3. 結果を確認する

秘書が完了報告をしてくれます。成果物は `company/` フォルダに保存されます。

## 組織のメンバー

| メンバー | どんな仕事をしてくれる？ |
|----------|----------------------|
| **秘書** | あなたの窓口。依頼を受けて各部署に仕事を振る |
| **PM部** | スケジュール管理・プロジェクト計画 |
| **開発部** | 技術調査・システム設計 |
| **マーケ部** | マーケティング戦略・コンテンツ作成・SNS |
| **営業部** | 提案書・台本・営業資料 |
| **経営企画部** | 売上分析・経営戦略 |
| **品質管理部** | できた成果物のダブルチェック |
| **CEO** | 大型タスクの戦略分析（呼び出し制） |

## コマンド一覧

| `/company setup cowork` | 子会社を設立する（初回のみ） |

## 実行モード

秘書に「全力で」「節約モードで」と伝えると、仕事の進め方を変えられます。

| モード | 特徴 |
|--------|------|
| **全力モード**（parallel） | 複数の部署が同時に動く。速い（デフォルト） |
| **順番モード**（sequential） | 1部署ずつ丁寧に進める |
| **おまかせモード**（inline） | 秘書が全部自分でやる。シンプル |

---

## 学習機能

使えば使うほど賢くなります。

- 各部署が仕事で得た知見を自動で記録（プレイブック）
- 次に似た依頼があると、過去の知見を活かして対応
- あなたの情報やプロジェクトの情報も記憶（共有メモリ）

## CLI版との違い

Cowork版では、ターミナル操作が必要な一部の機能を省略しています。
コア機能はすべて同じように使えます。

| 機能 | CLI版 | Cowork版 |
|------|-------|----------|
| 秘書への依頼・部署実行 | ○ | ○ |
| 並列実行（parallel） | ○ | ○ |
| CEO召喚（即時実行） | ○ | ○ |
| プレイブック（学習） | ○ | ○ |
| 共有メモリ | ○ | ○ |
| 品質管理レビュー | ○ | ○ |
| TODO管理・レポート | ○ | ○ |
| GitHub Issues連携 | ○ | — |
| リマインド通知 | ○ | — |
| CEO夜間スケジュール | ○ | — |
| 開発パイプライン（E2E） | ○ | — |

「—」の機能はCLI版（ターミナル）でのみ利用できます。
