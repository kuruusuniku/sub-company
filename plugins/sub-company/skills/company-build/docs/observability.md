# オブザーバビリティ基盤（Phase 1: 簡易トレーシング）

## 概要
サブエージェント実行のトレーシングログをMarkdownで記録し、
実行状況の可視化・デバッグ・コスト管理を可能にする。

## 実行ログのフォーマット

各命令実行時に `company/logs/YYYY-MM-DD-trace.md` にログを追記する。

### ログエントリのフォーマット
```markdown
### [HH:MM:SS] 命令 No.XXX — {部署名}

| 項目 | 値 |
|------|-----|
| 命令ID | XXX |
| 部署 | {部署名} |
| 件名 | {依頼内容の要約} |
| 開始 | HH:MM:SS |
| 完了 | HH:MM:SS |
| 所要時間 | {N}秒 |
| ステータス | ✅ 完了 / ❌ 失敗 / ⏳ 実行中 |
| エラー | {エラー内容（あれば）} |
```

### 日次サマリーのフォーマット
命令ログの末尾に日次サマリーを追記:
```markdown
## 日次サマリー

| 指標 | 値 |
|------|-----|
| 総命令数 | {N}件 |
| 成功 | {N}件 |
| 失敗 | {N}件 |
| 総所要時間 | {N}分 |
| 稼働部署 | {部署一覧} |
```

## ダッシュボード連携

`company/dashboard.md` に以下のセクションを追加する設計:
- 直近の実行ログへのリンク
- 週次トレンド（命令数・成功率・部署別稼働率）
