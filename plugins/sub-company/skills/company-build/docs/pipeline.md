# 3ツール間連携パイプライン

## 概要
サブカンパニー → 孔明チーム → タチコマチームの一気通貫パイプラインにより、
要件定義から並列実装までをE2Eで自動化する。

## パイプライン構造

```
Phase 1: サブカンパニー（要件定義・調査）
  ├─ PM部: 要件定義・タスク分解
  ├─ 開発部: 技術調査・フィージビリティ
  └─ 経営企画部: 市場調査（必要に応じて）
      ↓
  .context.md 生成（コンテキストファイル）
      ↓
Phase 2: 孔明チーム（設計）
  ├─ /koumei-start → 分析・設計・レビュー
  └─ 設計成果物を .context.md に追記
      ↓
Phase 3: タチコマチーム（並列実装）
  ├─ /tachikoma-plan → Issue/Wave計画
  ├─ /tachikoma-wave → 並列開発
  └─ /tachikoma-merge → マージ・PR
```

## コンテキストファイル（.context.md）

3ツール間でデータを受け渡すための統一フォーマット。
プロジェクトルートに `.context.md` として配置する。

### フォーマット
```markdown

## メタ情報
- 作成者: {サブカンパニー秘書名}
- 作成日: YYYY-MM-DD
- パイプラインフェーズ: phase-1 / phase-2 / phase-3
- 最終更新ツール: sub-company / koumei / tachikoma

## 要件定義（Phase 1: サブカンパニー）
### 背景・目的
{PM部の要件定義}

### 技術調査結果
{開発部の調査結果}

### 市場調査結果（該当する場合）
{経営企画部の調査結果}

### タスク分解
| # | タスク | 優先度 | 依存 |
|---|--------|--------|------|
| 1 | ... | 高/中/低 | - |

## 設計（Phase 2: 孔明チーム）
### 分析結果
{analyst の分析}

### UX設計
{ux-designer の設計}

### 技術設計
{tech-lead の設計}

### レビュー結果
{devils-advocate のレビューサマリー}

## 実装計画（Phase 3: タチコマチーム）

{Wave構造のサマリー}

### 実装状況
| Issue | Wave | ステータス |
|-------|------|-----------|
| ... | ... | pending/completed/failed |
```

## パイプラインの起動方法

### 秘書への依頼（推奨）
```
/sub-company:ask 開発パイプラインで {要件} を実装して
```

キーワード「開発パイプライン」「パイプラインで」「E2E開発」等が含まれる場合、
秘書はパイプラインモードで動作する。

### パイプラインモードのフロー

1. **Phase 1 実行**: 秘書がPM部・開発部にサブエージェントで要件定義・技術調査を指示
2. **コンテキスト生成**: 結果を `.context.md` に集約
3. **Phase 2 への引き継ぎ**: ユーザーに「孔明チームで設計を開始しますか？」と確認
   - 孔明がグローバルスキルとしてインストールされている場合 → 自動実行
   - インストールされていない場合 → 手動実行を案内
4. **Phase 3 への引き継ぎ**: ユーザーに「タチコマチームで並列実装を開始しますか？」と確認
   - タチコマのスキルが利用可能な場合 → `.context.md` からIssue・Wave計画を生成
   - 利用不可の場合 → 手動実行を案内

## 配布形態の違いへの対応

| ツール | 配布形態 | パイプラインでの呼び出し |
|--------|---------|----------------------|
| サブカンパニー | プラグイン | 常に利用可能（自身） |
| 孔明チーム | テンプレートコピー | プロジェクトにコピー済みなら利用可能 |
| タチコマチーム | グローバルスキル | `~/.claude/skills/` にあれば利用可能 |

### スキル利用可能判定
```bash
# 孔明チーム
ls .agents/TEAM.md 2>/dev/null  # プロジェクトにコピー済みか

# タチコマチーム
ls ~/.claude/skills/tachikoma-plan/SKILL.md 2>/dev/null  # グローバルインストール済みか
```
